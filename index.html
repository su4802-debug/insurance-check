여러 파일을 한 번에 끌어다 놓으면 종류를 자동으로 구분합니다 (.xls / .xlsx). 급여대장·직원명부는 두 메뉴가 함께 씁니다.

만들어지는 최종파일

세 파일이 모두 올라가면 바로 분석합니다. 결과 엑셀은 목적파일과 같은 구성으로 만들어집니다.

    2. 사업장별 요약

    사업장 표시명 바꾸기 (시트 이름에 쓰임 · 두 메뉴 공통)

    3. 이름 확인 필요

    고지서 성명을 급여대장에서 찾지 못했습니다. 이름이 다르게 등록된 경우 급여대장 이름을 골라 연결하면 이름구분에 저장되고 바로 다시 분석됩니다.

    4. 상세 비교

    이름구분

    A열 = 공단 고지서 성명, B열 = 급여대장 이름. 건강보험·국민연금 대사에 함께 쓰이고, B열이 채워진 행만 적용됩니다. 바꾼 내용은 이 브라우저에 저장되고 다음 분석에 반영됩니다.
